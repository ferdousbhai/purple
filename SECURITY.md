# Security Policy

## Supported versions

Security fixes are made on the latest release and the `master` branch. Older
releases are not maintained after a newer release is available.

## Reporting a vulnerability

Please report suspected vulnerabilities through a
[private GitHub security advisory](https://github.com/ferdousbhai/purple/security/advisories/new).
Do not include exploit details, API keys, chat contents, or other sensitive data
in a public issue.

Include the affected version, operating system, reproduction steps, and the
impact you observed. Reports involving generated Strudel code, the Tauri IPC
boundary, credential storage, remote assets, or release artifacts are in scope.

If GitHub's private reporting form is unavailable, contact the maintainer at
`ferdousbd@gmail.com` with the subject `Purple security report`.

The maintainer will acknowledge receipt and coordinate disclosure after a fix is
available. Please allow a reasonable remediation period before publishing
details.
